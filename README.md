# Control of an Endoscope Robot for Ear and Nose Surgery

## Description
This repository contains the inverse kinematics (IK), direct kinematics (DK), Jacobian computation, and singularity analysis of a parallel robot with a spherical mechanism.

The project also includes task-space trajectory planning implemented in MATLAB and Simulink, along with the corresponding Simulink models.

## Contents
- Inverse kinematics (IK)
- Direct kinematics (DK)
- Jacobian computation
- Singularity analysis
- Task-space trajectory planning
- MATLAB implementation
- Simulink models

## Documents
The included documents explain how the inverse kinematics, direct kinematics, and Jacobian equations are derived and computed for the spherical parallel robot mechanism.
